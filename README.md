# Business Data Analyzer

A dataset-independent beginner/intermediate analytics dashboard using Python, MongoDB, Streamlit, Pandas and Plotly.

## Features

- Upload CSV and Excel files
- Store dataset metadata and each row in MongoDB
- Dataset overview, missing-value and duplicate detection
- Column profiling and descriptive statistics
- Filter records and download filtered CSV
- Interactive bar, line, histogram, scatter, box and pie charts
- Correlation heatmap
- Rule-based automatic insights
- Save analysis snapshots in MongoDB
- Download analysis report and dataset
- Delete saved datasets

## Requirements

- Python 3.10+
- MongoDB Atlas account or local MongoDB

## Run on macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Run on Windows

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

## MongoDB setup

1. Create a free MongoDB Atlas cluster: https://www.mongodb.com/atlas
2. Create a database user and password.
3. In Network Access, allow your current IP address.
4. Choose Connect → Drivers → Python and copy the connection string.
5. Put the URI in `.env`:

```env
MONGODB_URI=mongodb+srv://USERNAME:PASSWORD@YOUR-CLUSTER.mongodb.net/?retryWrites=true&w=majority
MONGODB_DB=datalens
```

Replace the placeholders with your real credentials. URL-encode special characters in the password. Never commit `.env` to GitHub.

## Start

```bash
streamlit run app.py
```

Open the local URL shown in the terminal, usually http://localhost:8501.

## Start without Streamlit

The lightweight Flask version runs directly with Python and loads the included sample dataset:

```bash
python3 flask_app.py
```

Open http://127.0.0.1:5000. It supports CSV and Excel uploads, dataset summaries, column profiling, rule-based insights and CSV downloads. MongoDB persistence and the full interactive dashboard remain available through the Streamlit entry point above.

## MongoDB collections

- `datasets`: dataset name, filename, row count, columns and upload time
- `records`: one document per row, tagged with dataset_id
- `analysis_history`: saved summary snapshots

Rows are inserted in batches of 500. MongoDB has a 16 MB document limit, so rows are stored as individual documents rather than one large document.

## Demo dataset

`data/sample_sales.csv` is included. Upload it to test the dashboard.

## Limitations and next steps

- This is an academic project starter, not a production multi-user application.
- Pandas loads the selected dataset into memory. Very large files need pagination or distributed processing.
- Automatic insights are rule-based, not generated by an AI model.
- Add authentication, per-user permissions, file-size limits, validation and background processing before production deployment.
